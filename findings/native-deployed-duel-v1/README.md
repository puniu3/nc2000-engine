# Native current-default versus deployed comparison

Preregistered 192 games, 96 swaps. Current default native bot at runtime base 6c2bd9e versus deployed c7b11e8 bot, both without hp-type-evidence. Fixed 27000 iterations, UCB c=0.4, HP buckets 16. Same current corrected native referee for both, retaining each worker version own search and internal simulation engine. Native observation, including exact HP, matches the ordinary Web BlindSearcher lifecycle; no protocol importer, pinned sets, baked tables, community fallback prior or pondering. Uniform draws from the current 24-team catalog, same shipped weighted 103-team belief prior, common 32-bit bot seeds and battle seed within each swapped pair. Complete terminal games only; failures are not ties. Positive strength evidence requires pair-based betting95 lower bound above 0.5 after all 192 games. No optional stopping or adding seeds for significance. An interval containing 0.5 is inconclusive, not equivalence. Results are conditional on these rules, pool and equal iterations; not browser timing, human strength or full-game optimality evidence.

The new arena adapts learning_arena to the frozen native-wire-v1 worker. Only full native state is transported; workers receive no opponent action chosen in the current joint decision. Full snapshots are hashed and reproducible from initial teams, battle seed and recorded joint actions, avoiding quadratic archived log duplication. The independent native replay verifies every transferred-state fingerprint, legal choice, terminal outcome, turn, key and final PRNG seed.

Sixteen smoke games at 128 iterations cover current/current, deployed/deployed, current/deployed and its repeat. All identity trajectories and repeat records match except time/orientation. All 636 decisions replay. Seven record mutations are rejected by the Python audit; three separate native replay controls reject an altered outcome with matching score, terminal seed and snapshot fingerprint. Hidden Power executes in every smoke game. Smoke outcomes are excluded from the main result.
