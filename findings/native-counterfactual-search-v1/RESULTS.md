# Native counterfactual bot responses

All 210 eligible successors were searched with the ordinary native bot at 27,000 iterations: 45 original-continuation controls and 165 alternative continuations. All 45 controls exactly match the archived action, visits, means, search seed and state key. All 328 branch snapshots and non-response metadata match the frozen no-search census.

There are 151 distinct novel eligible successor states from 57 source games after deduplication and exclusion of original-continuation states. Selection did not use response quality. Full source replay covers 192 games, 4,498 states and 8,534 decisions. The independent census audit rejected four record mutations.

This establishes faithful measurements for a broader set of reachable continuations. It does not establish an action error, an improvement in bot strength, or a game-wide optimality bound. Ordinary bot behavior and deployment are unchanged.
