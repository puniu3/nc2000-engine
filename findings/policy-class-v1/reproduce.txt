The generic interval API is not connected to standard bot play. Input bounds must refer to an admissible continuation policy; sample means do not satisfy this contract automatically. The fresh game certificates use known actual loadouts and optimal continuation scores (win 1, tie 0.5). The finite-game tests separately validate full-policy improvement using the incumbent policy's actual continuation. The original 128-seed data are reused for output-selection ablations; no new statistical strength claim is made.
