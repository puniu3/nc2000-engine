# Combined HP correction and public evidence comparison

Fixed 192 full protocol-path games (96 paired swaps), candidate category correction plus hp-type-evidence versus pre-category local a48a40e without that feature. Uniform draws over the existing 24-team catalog, with the shipped weighted 103-team belief prior, no forced opening or hidden opponent information. Equal 27000 iterations and c=0.4, not equal wall time. Common battle and agent seeds within each swapped pair. One current native referee for both workers. This is a local intervention comparison, not deployed-bot superiority, general team-distribution superiority, human calibration or optimality proof. No optional stopping or adding seeds to seek significance. Report pair-based betting95 interval from the frozen evaluator; positive evidence only if its lower bound exceeds 0.5 after all 192 games. Non-significance is inconclusive, not equivalence. Exposure to public type constraints is reported separately; this combined intervention does not isolate category correction from type inference. Timings are Mac measurements only.

The research worker is the existing blind_worker with two read-only response fields: build feature status and observer type masks. Both builds use the identical helper. Runtime source hashes differ only in eval.rs; candidate compilation additionally enables hp-type-evidence. Existing learning_arena, learning-run and outcome evaluator are reused without edits. Catalog draws are uniform over its 24 entries, not its shipped cluster draw weights.

Smoke: 28 games at 128 iterations including two identity pairs, four repeated candidate/baseline games and sixteen exposure games. All actions are legal, protocol drift/projections are zero, identities and repeats match except timing, and seven invalid-record mutations are rejected. Type constraints occur in 13 candidate decisions across one exposure game. Smoke outcomes are excluded from the main strength estimate.

The native arena grants only each player frame; this differs from previous native state experiments with their exact-HP observation contract. Engine sleep/counter rules are unchanged. Full frames are recorded and terminal engine outcomes are required. A harness failure invalidates completion; it is not recorded as a tie.
