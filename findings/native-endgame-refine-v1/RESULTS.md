# Deeper screen across unresolved games

All 70 prespecified roots completed, one earliest unresolved root per game. Each used up to 250,000 engine executions, a 50,000-node stopping threshold and the same frozen helper/solver as the initial screen. Total engine executions were 11,559,118. There were 47 NodeBudget, 21 WorkExhausted and two StrategyMet stops. Batched expansions can cross the node stopping threshold; the maximum nodes-plus-closed count was 52,467.

Two previously unresolved selected-action loss intervals tightened below 0.02: game 7 frame 21, [0, 0.009930603576156716], and game 181 frame 97, [0, 0.018639168928377622]. The other 68 remained unresolved. No selected pure action had a loss lower bound above 0.02; none was proved strictly dominated. Combining both screens gives 38 small-loss roots from 38 games and 322 unresolved roots out of the original 360. This is neither a blind-policy optimality result nor a strength gain.

Every root and root-cell interval nested inside its initial-screen interval. The complete records passed independent rational LP matrix checks, action orientation and interval/loss checks, and the selection rule was recomputed from the frozen initial result. The two newly narrow roots and two unresolved controls were repeated; all fields except elapsed time matched. Helper/binary hashes matched the fixed protocol. The inherited audit also rejected the four record mutations when run on this refinement output. Three additional known-payoff controls explicitly verify that matching-pennies pure-action loss does not imply domination, that a dominated row is detected, and that the corresponding dominated-column result uses side-one orientation.

The main finding is a limitation of this analysis budget. Forty-seven roots hit the state-count threshold, and raising the compute budget tenfold resolved only two more roots. The unresolved cases include both healing and non-healing matchups. Further work should inspect unresolved graph structure and chance expansion, rather than interpreting inconclusive bounds as an optimal ceiling or blindly extending the same sweep.

All analyses fix the actual opponent loadout and hidden state and allow full-information optimal continuation. They use independent chance classes, not knowledge of the recorded RNG seed. Pure-action loss differs from the exploitability of a randomized policy. No model observation contract, runtime bot code, sleep-counter semantics, Counter rule or public deployment changed.
