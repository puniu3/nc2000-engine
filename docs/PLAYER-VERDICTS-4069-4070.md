## V2 — くろいまなざしで捕まった後は、ほろび0までのろいを積み切る

**前提**: ほろびカウントが1になるまでに、くろいまなざしを選択した側が倒されないこと。

**進行**:

```
ターン n   : くろいまなざしで相手を捕まえる
ターン n+1 : ほろびのうた → ほろび3
ターン n+2 : 死なないための時間稼ぎ、それができないならみちづれで相打ちを狙う → ほろび2
ターン n+3 : 死なないための時間稼ぎ、それができないならみちづれで相打ちを狙う → ほろび1
```

ターン n+2 / n+3 において、ほろびのうたを選択した側が交代する理由はない。

**正着見解**: この段階で捕まっている側にできるのは、この後交代で出てくるポケモンを一撃で倒して相打ちすること。**その確率を上げる唯一の行動が「のろいを選択し続ける」**。

**相手側の対抗選択肢（プレイヤーの補足）**: くろいまなざし＋ほろびのうたを選択した側も、交代したポケモンが相打ちされるとまずい場合、ほろびのうたを選択したポケモンをあえて引っ込めず、そのポケモンと相打ちするという選択肢がある。
