# 署名内情報価値実験（EXP-SIV v1）— メタプール構想の分岐点実験

Status: **COMPLETE (2026-08-11).** 設計・実装・本走・判定まで同日完了。**結論: §13** —
envelope（欺瞞価値）は実在するが、プール prior を持つ誠実なヘッジ相手には
署名内多様性の情報価値は予算とともに消滅する。メタプール構想は行列ナッシュ混合に縮退。
機械可読 gate: `data/exp-siv-v1/gate-result.json`。対象読者: オーナー + 実装セッション。
前提文書: `docs/M11-metagame-research.md`(山登りとまぐれ追い対策)、README M8/M10/M17b(混合価値・blind機構・プレレジ作法)。

---

## 1. この実験が決めること

メタプール構想(プール=混合戦略ナッシュ均衡、pool-as-prior、exploit耐性)の独自価値は
次の主張に懸かっている:

> **多様性は情報優位** — プールが多様だと相手は具体的な構成を特定できず、
> その不確実性そのものが得点になる。

この主張が偽なら、構想は「マッチアップ行列のナッシュ混合」(M8が既に台上で実証した
混合項、counter-pick margin 平均 +0.077)に縮退し、プールレベルの共進化・prior固定点・
重み付きbelief拡張は**全部不要**になる。真なら、その効果量が「プール最適化が取りに行く
賞金」の大きさであり、設計に署名内変種群を組み込む根拠になる。

どちらに転lんでも本走(double oracle)の設計が変わるので、**着工前にこれだけを安く測る**。

## 2. 理論的整理 — 情報項は「署名内」にしかない

チームプレビューで公開される情報(= belief のプレビューフィルタが使う情報)は
**種族 + レベル + アイテム所持有無**(M10a)。ここから:

- **署名が異なるチーム同士の多様性には情報価値がない。** プレビューの瞬間に
  相手のpriorは当該チームへ崩落する。異署名チームの混合の価値は純粋に
  マッチアップ混合(行列ナッシュ)であり、それは既にM8で測定済み。
- **情報項が存在しうるのは、同一署名を共有する変種(variant)の集合の内側だけ。**
  同じ6種族・同レベル・同アイテム所持の変種違い(技・アイテム内容・DV)は
  プレビューで割れず、beliefが複数候補を保持し続ける(Gate Bの衝突ペア機構が
  この状況の実働証明)。

したがって前チャットの「プールのエントロピーの関数として測る」は不正確で、正しい
処置変数は **署名内ambiguity(候補数k) × 持続性(何ターン割れないか) × 応答分岐
(候補ごとに相手の最適応答が変わるか)** の3つ。全プールのエントロピーはこの3つを
経由しない限り得点に影響しない。

**実験の論理は最良ケース殺し(kill test)**: H1に最も有利な条件——応答分岐を最大化
するよう人為設計した変種ペア——で情報項がゼロなら、進化的に生成される平凡な多様性に
情報項がないことはアフォルティオリで従う。

## 3. 仮説の形式化

記法: X = プール側(実験対象)、変種 v ∈ {A, B} を持つ。Y = 検証敵、固定チーム g
(T1ガントレットから)。X から見た g は常に公開(真ピン)。腕間で変えるのは
**Yの、Xのセットに関する信念だけ**。S = Xの得点(勝1/分0.5/負0)。

- **H0(帰無)**: 署名適合変種上のYの信念状態はXの期待得点を変えない。
  ∀(A,B,g,予算): E[S(v,g) | Y信念=¬v] − E[S(v,g) | Y信念=v] = 0
- **H1(対立)**: 応答分岐δのあるペアで上の差は正であり、δと探索予算に対して増加する。

## 4. 実験カスケード

| Phase | 問い | 機構 | 走る条件 |
|---|---|---|---|
| 0 | 計器は健全か | C1同一性 + C2牙チェック | 常に(最初に) |
| 1 | 情報価値の**上限**(envelope)は非零か | 真ピン vs 誤ピンの2×2 | Phase 0 green |
| 2 | blindヘッジは上限のうちどれだけ取り零すか | blind-with-prior vs 真ピン | Phase 1がH0棄却時のみ |

### Phase 1 が「誤ピン」で上限を測る理由

Yの情報条件の3点: 真を知る(真ピン) / priorでヘッジ(blind) / 誤を確信(誤ピン)。
Xの得点は通常この順に増える。blind測定はbelief機構込みで高価かつ分散が大きいので、
まず両端の差 = **envelope** を測る。誤ピンは**stubborn**(観測非反映、試合中も誤信念の
まま)で走らせる: これはリアルなヘッジ相手より情報価値を過大評価する向きの近似だが、
本実験の主目的はH0の確認棄却なので、**過大評価側に倒した上限がゼロなら結論は最強**
(最大限に騙され続ける相手からすら搾れない値は、更新する相手からは確実に搾れない)。
逆に正が出た場合の精密化はPhase 2(blind本測定、更新はネイティブ)が担う。

stubbornは実装も最小: `Belief::pinned` に署名適合な別セットを与え、観測マージを
凍結するだけ。determinizerは種族・レベルが公開状態と一致する限り機械的に整合する
(署名適合が必須条件——異種族ピンは公開状態と矛盾するので**不可**。C2の設計も
この制約内で行う)。

## 5. Phase 1 詳細設計

### 腕の構造(ペアp × ガントレットg ごとに2×2)

| | Y信念 = A | Y信念 = B |
|---|---|---|
| **真 = A** | S(A,真) 〔対角〕 | S(A,誤) |
| **真 = B** | S(B,誤) | S(B,真) 〔対角〕 |

- 方向別効果: D_A = S(A,誤) − S(A,真)、D_B = S(B,誤) − S(B,真)
- **envelope(p,g) = (D_A + D_B) / 2**(方向別も報告)
- 対角同士の差 = 変種の強度マッチ検定(追加費用ゼロで同じ走から出る)

### ペアリング(分散対策 — このリポジトリの標準作法)

- 4セル全部で**同一のbattle-seedリスト**を共有、セル内で先後入替(side-swap)。
- 探索rngシードはduelハーネスの規約どおりゲーム毎に決定的導出。
- 効果は**シードごとの対差分**として集計(チーム固有の強さはペアリングで相殺)。

### 規模と予算

| 項目 | 値 | 根拠 |
|---|---|---|
| ペア数 | 4(応答分岐スクリーン上位から) | 用量反応軸を確保しつつ費用抑制 |
| g | T1から2チーム(アーキタイプ対照: 崩し系/受け系) | 敵依存性の粗い層別 |
| n/セル | 256(128シード×先後) | 下記CI計算 |
| 予算 | 主 **3000**(Gate Aと同じ)、先行パス1000、最大分岐ペアに10kスポット | 予算転移の疑い(M17a/bの教訓)への手当て |
| 両者エージェント | X: 対gピンのopen相当 / Y: ピン(真or誤) | belief機構最小、Phase 1はフィルタ不要 |

CI概算(対差分sd≈0.6と保守的に置く): 方向別/セル ±0.073、envelope/(p,g) 512差分で
±0.052、**ペア別(g合算) ±0.037、全体プール 4096差分で ±0.018**。全体CIで 0 と +0.05
を分離できる。

計算費(skuct系 ≈ 0.33ms/iter/move、M11実測 skuct:300 ≈ 11s/game単スレから線形外挿):
1000パス ≈ 6–8h、3000パス ≈ 15–25h、10kスポット(1ペア4セル) ≈ 6–10h、
**合計: 現マシン(10スレッド, nice)で夜3回分**。全セルresumable必須(bakeの型)。

## 6. 操作チェックと計器チェック(フラット結果を解釈可能にする装置)

主セルの「差なし」がH0の証拠になるのは、以下が**全部同時に**成立する場合のみ。

- **C1(同一性・負のコントロール)**: k=1 — Yを「真ピン経路」と「単集合プールのblind
  経路」の両方で走らせ、差が±0.02以内(構造的にはほぼビット同一のはず。Gate B流の
  決定化同値アサートをサンプルに掛けてもよい)。**逸脱 = ハーネスバグ、全結果無効。**
- **C2(牙・正のコントロール)**: Yを**弱体化セット**(M11aの弱体化オペレータ:
  アイテム剥ぎ+技ダウングレード、署名は同一)に誤ピンし、Xの得点が明確に上がる
  (下限 > +0.05)ことを確認。極端な誤信念すら得点に変換されないなら、主セルの
  フラットは「情報が無価値」でなく「**計器が情報効果を解像できない**」と区別不能に
  なる——その場合は主実験を走らせず診断(予算を10kに上げてC2再走)に回る。
- **応答分岐スクリーン(ペア採用の事前条件)**: Y(skuct:2000相当)のroot方策を
  「対A信念」「対B信念」で取り、プレビュー選出のTV距離 ≥ 0.3 または top-1選出の相違
  を要求。分岐しないペアは**採用しない**(そのフラットはH0の証拠に数えない)。
  分岐スコアはペアの用量反応軸として記録。数分/ペアの費用。
- **強度マッチ**: 対角差 |S(A,真)−S(B,真)| ≤ 0.08(プレレジ)。超過ペアは除外。

## 7. 帰無仮説が真なら、どんな条件で何が観測されるか

H0が真で実験が健全なとき、観測は次の**連言**になる:

| # | 観測点 | H0真・実験健全 | H1真 | 実験不成立のシグナル |
|---|---|---|---|---|
| 1 | C1 同一性 | 0(±0.02) | 0 | ≠0 → ハーネスバグ |
| 2 | C2 弱体化誤ピン | **明確に正**(セット情報自体は価値を持つ) | 明確に正 | ≈0 → 計器盲、主セル解釈不能 |
| 3 | 主セル: envelope(全ペア×g) | **フラット**: pooled 95%CI ⊂ (−0.05,+0.05)、ペア別もBH補正で有意なし | 分岐上位ペアで正、pooledの下限>0 | — |
| 4 | 応答分岐スクリーン | **分岐は閾値以上**——応答は変わるのに利得が変わらない、これがH0の核心の観測 | 分岐あり+利得差あり | 分岐なし → 変種設計失敗、やり直し |
| 5 | 用量反応(分岐スコア軸/予算軸1000→3000→10k) | 傾き≈0、予算を上げても立ち上がらない | 正の傾き(強い探索ほど情報を搾る) | — |
| 6 | 強度マッチ | 対角差 ≤0.08 | 同左 | 超過 → 当該ペア除外 |
| 7 | (Phase 2到達時のみ)信念持続 | — 到達しない | 候補数が中盤まで>1のまま Δ_blind>0 | 即崩落 → 分岐軸が早期リーク、変種再設計 |

一言でいえば: **「相手は変種ごとに違う応答を取っている(#4)のに、どの応答を取られても
得点が変わらない(#3)、そしてその不感応が予算にも分岐度にも依存しない(#5)」** ——
これがH0の観測署名。#1 #2 #4 #6 が green でない限り #3 のフラットはH0の証拠にならない。

C2≈0 の縮退ケースについて: 「計器盲」と「この予算ではセット情報が本当に無価値」は
区別しにくいが、**どちらでも情報項ブランチは死ぬ**(製品予算で搾れない価値は製品価値
ではない)。診断として10kでのC2再走のみ行い、区別は記録に留める。

## 8. 判定ルール(プレレジ案 — 本走前にオーナー承認で確定)

主要評価項目: **3000予算・stubborn envelope の全ペアpooled値**。

- **H0適合(futility)**: pooled 95%上限 < +0.05 が1000と3000の両方で成立、かつ
  BH補正でペア別有意なし、かつ §6 全チェックgreen。→ 情報項なしと結論。
- **H0棄却(Phase 2へ昇格)**: pooled 95%下限 > 0 かつ点推定 ≥ +0.05、または
  単一ペアがBH有意かつ点推定 ≥ +0.10。→ 当該軸でPhase 2(blind本測定)を設計。
- **どちらでもない**: プレレジ済みの延長を**1回だけ**(分岐スコア上位2ペアのnを倍増)。
  それでも跨ぐなら区間を最終値として記録し、事後の再解釈はしない(M17bの作法)。

閾値 +0.05 の根拠: M8の混合項(+0.077)、Gate Aのblind全ギャップ(0.057)と同スケール。
これ未満の情報項は、prior固定点機構を本走に組み込む工費・計算費に見合わない。

### H0確定時の帰結(この実験の存在意義)

- メタプール設計は**異署名チーム上の行列ナッシュ + double oracle**に縮退。
  prior固定点反復・重み付きbelief・署名内変種生成を本走計画から削除(数日分の計算減)。
- 「exploitされにくい」の物語は混合項のみで語る。プールの「多様さ」のUX価値は残るが、
  それは読み合い攪乱ではなくマッチアップ混合+演出。
- Phase 2は永久に走らない。

### H1確定時の帰結

- Phase 2で Δ_blind(製品関連量)を定量: Y = blind + 一様prior(候補k∈{2,4,8}は
  **既存機構で足りる** — beliefは候補一様をネイティブ対応、重み付きはまだ不要)、
  信念幅ログ(beliefInfo流用)で持続性を操作チェック。規模はPhase 1の結果を見て設計。
- 本走のdouble oracleに署名制約付き変種生成(teamgenに署名保存モード)を追加する
  根拠が立つ。効果量がそのまま優先度になる。

## 9. 変種ペアの構成手続き

制約(署名適合): 種族・レベル・性別・色違い・アイテム所持有無が一致、双方
validator-clean、プレビューフィルタが両候補を保持することをユニットテストで担保
(Gate Bの衝突ペアテストの型を流用)。

分岐軸の例(採否は§6のスクリーンが決める。正確なセットは実装時にオーナーの
メタ入力を任意で受ける):

- **大爆発の有無**(Snorlax/Cloyster: boom型 vs Rest型 — ゴースト受け・裏選出が変わる)
- **眠り技の有無**(Lovely Kiss/Hypnosis の有無 — 眠り対策の立ち回りが変わる)
- **4枠目のカバー技タイプ**(地震 vs 大文字 等 — 安全な受け出し先が変わる)
- **補助プラン差し替え**(まきびし/どくどく vs 追加アタッカー)

Phase 2の持続性のため、リード初手で即割れる軸より**中盤以降に割れる軸**(控えの技、
発動条件付きアイテム)を優先する(Phase 1のstubbornでは無関係だが同じペアを使い回す)。

4. (Phase 2のみ、条件付き) プールファイルblind腕 + 信念幅ログ。+1セッション。

計算費(再掲): **現マシンで夜3回分**(1000パス→3000パス→10kスポット)。
Phase 2が走る場合 +2〜3晩。

## 12. 実施記録と設計修正（2026-08-11、envelope本走の開封前に記載）

実装セッションの環境はオーナー機ではなくクラウドコンテナ(4コア)。実測 ~52 ms/move
@1000反復(オーナー機の約6倍/コア)だったため、規模を**縮小でなく拡大**して確定:

| 項目 | 設計時 | 実施 |
|---|---|---|
| 主走 | 3000×256戦/セル | **1000×256戦/セル + 3000×128戦/セル の二予算フル実施** |
| ペア | 4 | 2(lax-eggy: カビゴンboom/ナッシー爆発の2匹軸; zapdos: サブいばる/眠る寝言の1匹軸)— 用量対照は「軸の数」で取る |
| g | 2 (hc75-1st-show / hc75-top8-tsuru) | 同じ |
| C1/C2 | budget別 | **両予算で実施**(C2の牙は測定予算ごとに要る) |
| シード | セル間共有 | セル間+予算間で共有(battle seed列とagent seedはセル無依存に導出) |

**修正1 — stubbornの実装形。** `Belief::freeze_pinned`: sync のfail-closed検査を
スキップし、determinize が観測チャネル(revealed moves / item知識)をスクラブして
候補をverbatimに賦課する。**reveal-mergeも無効**(純stubborn)。真ピン腕は凍結しない
製品セマンティクス(既revealed技のPP追跡が生きる)——腕間の非対称は「真ピン=製品挙動、
誤ピン=凍結が存在条件」として設計どおり。

**修正2 — C1の実装形。** open腕 = `Belief::pinned_from_battle`(真ロスターclone、
製品のOpenAgent)、真ピン腕 = セットからの `Belief::pinned`(build_refs構築)。rng
ストリームが異なるためビット同一でなく**統計同一**の検定になる。

**修正3 — 応答分岐スクリーンの改訂と、その最初の読み。** 設計§6のスクリーンに
シードノイズ床(同一信念内のシード間ペアワイズTVD)を追加した(eval-candidate-screen
の教訓)。**2000反復での結果: 全ペア×g で across/within 比 1.02〜1.12 — プレビュー
方策は信念を分離しない**(方策全体がシードノイズ支配。top-1は同一信念内でもシードで
割れる)。したがって§6の「分岐しないペアは採用しない」をプレビュー方策基準のまま
適用すると全ペア不採用になるが、これは**計器の解像度不足**(プレビュー根はエージェント
予算では常時undersampled)と、分岐軸が本質的に戦闘中(boom警戒・眠り警戒・受け出し先)
にあることの帰結と判断し、次の通り修正する: プレビュースクリーンは採否ゲートでなく
**解釈材料**に格下げ、20k反復の高予算スクリーンを追加実施、そして「応答分岐が実在する
か」は主にC2(牙)と envelope 自身が担う。ヌル結果の解釈条件(§7の連言)は「#4 スクリーン
green」を「C2>0 かつ 20kスクリーン記録」に差し替える。この修正は envelope セルの
数値を見る前に記録した(probe走 n=4/セル の煙数値のみ既見、判定に使わない)。

**修正4 — 判定規則。** futilityバーは不変(grand 95%上限 < +0.05、**両予算で**)。
10kスポットは 1000/3000 の結果を見てから、事前規則どおり「最大分岐ペア」に対して

## 13. 結果と判定（2026-08-11）

全数値は seed-paired ブロック対差分の mean ± 95%CI。生データ: `data/exp-siv-v1/cells/`、
機械可読 gate: `data/exp-siv-v1/gate-result.json`。

### 計器チェック — すべて green

| C1 同一性 (open − 真ピン) | −0.047±0.083 | −0.031±0.109 | 0を跨ぐ。ただし分解能は±0.08〜0.11(設計の±0.02には届かず) |
| C2 牙 (弱ピン − 真ピン) | **+0.219±0.078** | **+0.227±0.102** | 明確に正 — 計器はセット情報効果を見える |

| 20kスクリーン | — | — | 4組中3組で床の1.36〜1.45倍(2000では床と不可分) |

### Phase 1 — envelope: **H0棄却**

| | grand | zapdos-g4(最大分岐ペア) |
|---|---|---|
| 1000 | **+0.055 [+0.025, +0.085]** (n=1024) | +0.106±0.059 (BH有意 p=4.3e-4) |

昇格規則は両ルート(grand点推定≥+0.05かつ下限>0、単独ペアBH有意かつ≥+0.10)で成立。
8セル全て正符号。**誤った確信は出血する** — 相手のセットを間違って確信した敵は、
zapdos-g4 で最大 +0.31(D_A@3000)を明け渡す。envelope は予算とともに維持・増加。

### Phase 2 — Δ_blind: **ヘッジは envelope をほぼ全額取り戻す**

| | grand | zapdos-g4 |
|---|---|---|
| 1000 | +0.032 [+0.004, +0.061] | +0.078±0.057 |
| 3000 | **−0.014 [−0.053, +0.026]** | +0.008±0.080 |
| 10000 | — | **−0.073±0.093** |

信念は決定の3〜7割(zapdos-g4では77%)で2候補のまま割れていない。それでも
**Δ_blind はヘッジ側の予算に対して単調減衰し、10kでゼロを割る**。envelope の用量
(増加)と正反対 — 強い探索は「誤確信」を搾る力を増すが、「正直な不確実性」は
determinization ヘッジで無力化する。全予算で materiality バー(+0.05)未満。
製品予算(30k)への外挿は明確に ≤0。

### 判定

- **H0(素朴形)は偽**: 署名内のセット情報は価値を持つ — ただし**相手が誤った読みに
  コミットする場合に限る**(envelope)。
- **メタプール構想の前提(多様性は情報優位)は、構想が想定する相手そのもの —
  プールを prior として持つ blind 相手 — に対して死んでいる**: 持続する不確実性は
  製品級予算のヘッジで無価値化される(Phase 2)。
- **設計帰結はプレレジの H0 分岐と同じ**: 本走(double oracle)は異署名チーム上の
  行列ナッシュ混合に縮退。prior 固定点反復・重み付き候補 belief・署名内変種生成は
  本走計画から削除。混合項(M8 の +0.077)がプールの独自価値として残り、envelope は
  その混合項が守っている当のもの(「読みへのコミットは出血する — だからコミットせず
  ヘッジせよ」)を定量化した、という読みで整合する。

### 留保

- ペア2種・敵2チーム・1フォーマット。効果はマッチアップ依存が強い(zapdos-g4 支配)。
- 30k は直接測定していない(1k/3k/10k からの単調外挿)。
- 「読みにコミットする人間」から envelope 相当を回収する路線は opponent modeling で
  あり、リポジトリの non-goal(搾取なし)により対象外。
